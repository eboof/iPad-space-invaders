# iPad Space Invaders

A retro Space Invaders-style game built for Safari on iPad.

## Features
- Touch controls for iPad
- Keyboard controls for desktop testing
- Score, lives, levels
- Enemy waves, player bullets, enemy bullets
- Win/lose loop with restart

## Run locally
Because this is static HTML/CSS/JS, you can run it with any local web server.

### Python
```bash
python3 -m http.server 8000
```

Then open:
- `http://localhost:8000`

## Controls
### iPad
- Drag on the game area to move
- Or hold the left/right buttons
- Tap `FIRE` to shoot

### Keyboard
- `←` / `→` to move
- `Space` to fire
- `Enter` to start/restart
